# Hi, I’m dotori.

I build mobile security SDKs for Android and iOS. My work spans native development, platform compatibility, and security detection.

I also build tools and agent skills for setting clear goals, understanding code changes, and explaining technical work.

## What I’m focused on

I want to understand the core logic of AI-generated code before moving on. I built Baby Steps to make that understanding part of development through small, reviewable steps.

I’m exploring code reviews grounded in team rules, system context, and change history. I’m also working on ways to define measurable goals before handing work to an agent and to write clear technical Korean without losing conditions, exceptions, or uncertainty.

## Selected projects

- [Korean Humanizer](https://github.com/dotoridot/korean-humanizer): An agent skill for making Korean writing more natural while preserving its meaning
- [DocPilot](https://github.com/dotoridot/docpilot): A desktop Markdown editor with Claude and Codex sessions, where you can review file changes before accepting them
- [DOT-STK100](https://github.com/dotoridot/DOT-STK100): An independent writing specification and agent skill for clear technical Korean, with rules for preserving technical meaning
- [goal-setting-skill](https://github.com/dotoridot/goal-setting-skill): A Claude skill for turning a conversation about goals into a brief with measurable targets and guardrails for an agent
